# Android-приложение M-TELECOM SALES

Нативный клиент на Kotlin + Jetpack Compose. Это не сайт в WebView.

## Совместимость

- Минимум: **Android 8.0 (API 26)**
- Цель сборки: API 34
- Язык интерфейса: русский (архитектура строк позволяет позже добавить казахский)

## Возможности менеджера

- Вход по логину и паролю, токен в EncryptedSharedPreferences / Android Keystore
- Главный экран с живой статистикой из API
- Список и карточка клиента
- Создание физлица и юрлица, предупреждение о дублях
- Кнопки «Позвонить по SIM» и «WhatsApp»
- Фиксация результата разговора (клик по кнопке звонка сам по себе разговором не считается)
- Если есть разрешение `READ_CALL_LOG` и система вернула длительность звонка на номер клиента — запись помечается «Подтверждено системой»
- Иначе менеджер вносит данные вручную с пометкой «Внесено менеджером»
- WhatsApp не читается скрытно: фиксируется факт открытия и ручной результат
- Задачи на сегодня / просроченные
- Очередь действий без интернета (Room + WorkManager), повтор без дублей за счёт UUID / Idempotency-Key
- Проверка версии APK на сервере и предложение скачать обновление (установка только с подтверждением пользователя)

Не реализуется и не планируется: скрытая запись разговоров, слежка за личными звонками, чтение переписки WhatsApp.

## Сборка

Нужны JDK 17 и Android SDK 34.

1. Установите Android Studio Hedgehog или новее.
2. Откройте папку `android/`.
3. Создайте `android/local.properties`:

```
sdk.dir=C:\\Users\\ИМЯ\\AppData\\Local\\Android\\Sdk
```

4. Debug:

```
gradlew.bat assembleDebug
```

Файл: `android/app/build/outputs/apk/debug/app-debug.apk`

5. Release — создайте keystore вне git и соберите `assembleRelease`.

## Установка на телефоны менеджеров

1. Разрешите установку из неизвестных источников (или загрузите APK через корпоративный канал).
2. При первом запуске укажите адрес сервера, например `https://sales.mtelecom.kz`.
3. Войдите логином менеджера.
4. Разрешите телефон и журнал вызовов, если нужна системная длительность звонка. Без разрешения работа сохраняется, длительность вносится вручную.

## Обновление

Сервер отдаёт `GET /api/app/version`. Если `version_code` больше установленного, приложение предлагает скачать APK. Скрытая установка не выполняется. Журнал версий хранится в таблице `app_versions` — можно оставить предыдущую стабильную запись.

## Безопасность клиента

- Пароль на устройстве не хранится
- Токен только в Keystore-backed EncryptedSharedPreferences
- Базовый URL задаётся на экране входа, в APK нет паролей сервера
- Блокировка менеджера на сервере отзывает все токены
