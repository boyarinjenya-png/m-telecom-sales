# Ручная проверка WhatsApp на реальном Android-телефоне

Документ для менеджера/QA. Цель — подтвердить, что M-TELECOM SALES корректно открывает WhatsApp / WhatsApp Business для номеров Казахстана и не падает, если приложение отсутствует.

## 0. Что проверить заранее

| Параметр | Ожидание |
|---|---|
| Установленный APK | Debug: `kz.mtelecom.sales.debug` **или** Release: `kz.mtelecom.sales` |
| Сервер на экране входа | Тест или `https://mtelecom.kz/sales` / `https://sales.mtelecom.kz` |
| Учётка | Менеджер с доступом к тестовому клиенту |
| Телефон клиента в карточке | Заранее заведите 3 варианта номера (см. ниже) |

**Не смешивайте** debug и release на одном телефоне без удаления: у них разные `applicationId`, это два разных приложения.

## 1. Подготовка устройств

Нужны по возможности два прохода (можно на одном телефоне по очереди):

1. **С WhatsApp** (обычный `com.whatsapp`).
2. **Только WhatsApp Business** (`com.whatsapp.w4b`) — обычный WhatsApp удалён/отключён.
3. **Без обоих** — для проверки fallback.

Создайте в CRM клиента(ов) с телефонами:

| ID теста | Ввод в карточке | Ожидаемый номер в WhatsApp |
|---|---|---|
| KZ-8 | `87001234567` | `+77001234567` / `77001234567` |
| KZ-plus | `+7 700 123 45 67` | тот же международный `7700…` |
| KZ-7 | `77001234567` | без изменений по цифрам |

Подставьте реальный тестовый номер, на который у вас есть WhatsApp.

## 2. Сценарий A — чат WhatsApp

1. Откройте карточку клиента.
2. Нажмите кнопку **WhatsApp**.
3. Зафиксируйте:
   - открылось ли приложение WhatsApp / Business (не «голый» браузер в первую очередь, если WA установлен);
   - совпадает ли номер с ожидаемым (нет ведущей `8`, нет пробелов в цифрах);
   - после возврата в M-TELECOM SALES появился ли диалог **результата контакта**.
4. Выберите результат (например «Нет ответа» / «Договорились») и сохраните.
5. Обновите карточку — событие WhatsApp должно отображаться в истории.

**Критерий OK:** чат + нормальный номер + запись в CRM.

## 3. Сценарий B — звонок WhatsApp

1. В карточке: **Ещё** → **Звонок WhatsApp**.
2. Возможные исходы (оба допустимы):
   - **Идеал:** открывается UI звонка WhatsApp на этот номер;
   - **Fallback:** deep-link звонка не поддержан прошивкой/версией WA → открывается чат с тем же номером.
3. Вернитесь в CRM, сохраните результат контакта (для звонка WA укажите длительность вручную, если форма просит).

**Критерий OK:** нет краша; номер тот же; результат сохраняется; в истории видно WhatsApp-событие / звонок.

## 4. Сценарий C — только WhatsApp Business

1. Удалите или отключите обычный WhatsApp.
2. Оставьте установленным WhatsApp Business.
3. Повторите сценарии A и B.

**Критерий OK:** действия уходят в Business; номер корректный; CRM работает как раньше.

## 5. Сценарий D — WhatsApp не установлен

1. Удалите / отключите WhatsApp и Business.
2. Нажмите **WhatsApp**.
3. Ожидание:
   - открывается Play Store (карточка WhatsApp) **или** браузер с `wa.me/…`;
   - приложение M-TELECOM SALES **не закрывается с ошибкой**.
4. По возможности вернитесь в CRM и отметьте результат вручную, если диалог результата показан.

**Критерий OK:** контролируемый fallback, без crash.

## 6. Сценарий E — форматы казахстанского номера

Для каждого из трёх форматов (раздел 1) повторите только открытие чата и сверку номера в шапке WhatsApp.

**Критерий OK:** все форматы приводят к одному и тому же `7700…`.

## 7. Регрессии вокруг заявки / офлайна (кратко)

Не часть WhatsApp, но удобно на том же телефоне:

1. Включите авиарежим.
2. Создайте заявку по клиенту («Создать заявку»).
3. Убедитесь, что приложение сообщает о сохранении в очередь (не «тихий» провал).
4. Выключите авиарежим, дождитесь синка / нажмите синхронизацию.
5. Статус клиента — «Заявка получена», без дублей при повторном синке.

## 9. Типичные сбои

| Симптом | Что проверить |
|---|---|
| Открывается браузер при установленном WA | Выбор приложения по умолчанию; переустановка WA |
| Номер с `8` или без `7` | Баг нормализации — приложить исходный `phone_primary` из карточки |
| Звонок сразу в чат | Нормальный fallback; указать версию WA |
| Crash при отсутствии WA | Регресс `PhoneActions` — нужен logcat |
| Debug APK «не обновляет» старый | Смотрите `applicationId` и сертификат (см. RELEASE-SIGNING.md) |
