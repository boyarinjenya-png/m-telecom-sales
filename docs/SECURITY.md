# Безопасность

- Пароли только через `password_hash` / `password_verify`.
- Токены: 32 случайных байта, в БД хеш SHA-256, TTL настраивается.
- PDO, валидация входа, экранирование HTML в кабинете.
- CSRF для cookie-сессии кабинета (`X-CSRF-Token`).
- Загрузка только JPG/PNG/WEBP, лимит размера, случайные имена.
- Ограничение попыток входа.
- Журнал `audit_log`.
- HTTPS обязателен в production (`APP_URL=https://...`).
- Секреты только в `.env`, файл в `.gitignore`.
- Блокировка менеджера отзывает API-токены и веб-сессии.
- Android: токен в Keystore, `allowBackup=false`.
- Нет скрытого прослушивания и нет доступа к личным звонкам: учитываются только действия из карточки клиента.
