# Развёртывание на Hoster.KZ

Не публиковать и не менять основной сайт без отдельного подтверждения владельца.

## Что проверить в панели до выкладки

1. Версия PHP ≥ 8.2 (для поддомена/каталога Sales можно включить отдельно).
2. MySQL/MariaDB и возможность **новой** базы.
3. HTTPS / Let's Encrypt для `mtelecom.kz` (поддомен обычно покрывается тем же сертификатом или выпускается отдельно).
4. Можно ли создать поддомен `sales`. Если нет — каталог `/sales`.
5. Git-деплой основного сайта не использовать для этой системы.

## Рекомендуемый порядок

1. Создать БД `mtelecom_sales` и пользователя только для неё.
2. Создать поддомен `sales.mtelecom.kz` **или** каталог `/sales`.
3. Загрузить файлы проекта (FTP/SFTP/отдельный git pull в отдельную папку).
4. Document root → `backend/public`.
5. Права записи на `backend/storage`.
6. Открыть `/install.php`, заполнить параметры, создать ADMIN.
7. Удалить или оставить `install.lock`. Форму установки повторно не открывать.
8. Проверить:
   - `https://sales.mtelecom.kz/api/health`
   - вход в кабинет
   - создание тестового менеджера
9. Собрать APK и указать в приложении этот HTTPS-адрес.
10. Настроить выгрузку SQL раз в сутки (панель или cron, если тариф даёт cron).

## Если автоматический Git-деплой недоступен

Выкладывать ZIP/SFTP в отдельный каталог Sales. Не нажимать «подключить тот же репозиторий», которым публикуется основной сайт.

## Откат

Вернуть предыдущие файлы приложения и импортировать SQL-копию. Основной сайт при этом не трогать.
